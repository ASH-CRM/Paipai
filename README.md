# PAI PAI · ผู้ช่วย AI

แอปผู้ช่วยเดินทางสำหรับผู้ใช้กลุ่มเล็ก
- **หน้าแรก:** ล็อกอินด้วย PIN
- **เข้ามาแล้ว:** เจอผู้ช่วย AI ให้คุยและสั่งงานได้ทันที
- **สั่งเมนูได้:** AI ไปทำงานในเมนูของ PAIPAI ให้เอง แล้วแสดงผลในกรอบครึ่งล่างของจอ

ตัวอย่างคำสั่ง
- "จัดทริปญี่ปุ่น 5 วันที่โตเกียว" → AI เปิด **Plan Pai** จัดตารางเที่ยวให้ แล้วสรุปไฮไลต์
- "จากสถานีชินจูกุไปโตเกียวทาวเวอร์ยังไง" → **Pa Pai** หาเส้นทางรถไฟ
- "หาที่พักแถวชินจูกุ" → **Pak Pai**
- "ไปญี่ปุ่นจ่ายเงินยังไง" → **Jai Pai**
- "เรียกรถไปโตเกียวทาวเวอร์" → **Riak Rot** (ผู้ใช้แตะเลือกแอปเอง)
- "เปิดตัวแปลภาษา" → **translator56**

## มีอะไรบ้าง

- **ล็อกอินด้วย PIN:** เลือกรูปประจำตัว แล้วใส่ PIN ตัวเลข 4–8 หลัก
  - ใส่ผิด 5 ครั้งติดกัน บัญชีจะล็อก 15 นาที
  - ระบบเก็บเฉพาะค่าแฮชของ PIN ไม่เก็บตัว PIN จริง
  - เปิด `paipai.html` ตรงๆ โดยไม่ได้ล็อกอิน ระบบจะพากลับไปหน้าล็อกอิน
- **จัดการผู้ใช้ (เฉพาะผู้ดูแล):** กดรูปตัวเองมุมขวาบน → จัดการผู้ใช้ เพื่อเพิ่ม แก้ไข ตั้ง PIN ใหม่ ระงับ หรือลบผู้ใช้
- **หน้าผู้ช่วย:** คุยต่อเนื่องอย่างเดียว ไม่มีรายการให้เลือก
  - กด 🎤 เพื่อพูดสั่งงาน
  - กด ↺ เพื่อเริ่มคุยใหม่
  - บทสนทนาแยกของแต่ละคน
- **กรอบด้านล่าง:** แสดงเมนู PAIPAI ที่ AI กำลังทำงานให้
  - กด ⤢ เพื่อขยายเต็มจอ
  - กดรูปตัวเอง → "เปิดเมนู PAIPAI" เพื่อใช้แอปเองได้

ไอคอนผู้ช่วยตอนนี้เป็นตัวชั่วคราว เปลี่ยนดีไซน์ได้ที่ `.orb` ใน `public/index.html`

## วิธีนำขึ้น Netlify

ตอนนี้แอปมีขั้นติดตั้งแพ็กเกจแล้ว ต้องให้ Netlify ดึงโค้ดจาก GitHub และ build เอง **ลากไฟล์ zip ขึ้นเว็บแบบเดิมใช้ไม่ได้แล้ว**

1. Netlify → เว็บ PAIPAI เดิม → **Project configuration → Build & deploy → Link repository**
   (หรือสร้างเว็บใหม่: **Add new project → Import from GitHub**) แล้วเลือก repo `ASH-CRM/Paipai`
2. **Branch:** branch ที่มีงานนี้ (หลัง merge แล้วใช้ `main`) · **Base directory:** เว้นว่าง
   - ค่าอื่นระบบอ่านจาก `netlify.toml` เอง (publish = `public`)
3. ตั้ง Environment variables ที่ **Project configuration → Environment variables**

   | ชื่อ | ค่า |
   |---|---|
   | `ANTHROPIC_API_KEY` | คีย์ Claude (ถ้าเว็บเดิมมีอยู่แล้ว ไม่ต้องตั้งใหม่) |
   | `SETUP_CODE` | รหัสลับที่ตั้งเอง ใช้ครั้งเดียวตอนสร้างผู้ดูแลคนแรก |
   | ตัวแปรเดิมของเว็บ (เช่นคีย์ Google Maps) | คงไว้เหมือนเดิม |

4. Deploy แล้วเปิดเว็บ → ใส่ `SETUP_CODE` ชื่อ และ PIN → ได้บัญชีผู้ดูแล
5. เพิ่มผู้ใช้คนอื่นที่เมนู **จัดการผู้ใช้** แล้วแจ้ง PIN ให้แต่ละคน

ข้อมูลผู้ใช้และบทสนทนาเก็บใน Netlify Blobs ของเว็บนี้ ไม่ต้องสมัครฐานข้อมูลเพิ่ม

## โครงสร้างไฟล์

```
├── netlify.toml                 ตั้งค่า Netlify (publish = public)
├── package.json                 แพ็กเกจ: @anthropic-ai/sdk, @netlify/blobs
├── lib/auth.mjs                 PIN, โทเคน, ผู้ใช้, การล็อก
├── lib/chat.mjs                 คุยกับ Claude + รายการเครื่องมือสั่งเมนู
├── netlify/functions/api.mjs    API ผู้ช่วย (/api/*)
├── netlify/functions/*.js       API เดิมของ PAIPAI (แปลภาษา, Google Maps, Navitime)
└── public/
    ├── index.html               หน้าล็อกอิน + หน้าผู้ช่วย
    ├── paipai.html              แอป PAIPAI เดิม (+ window.PAIPAI_AGENT ให้ AI สั่งเมนู)
    └── sw.js, manifest.json, icon-*.png
```

### AI สั่งเมนูยังไง

1. ฝั่งเซิร์ฟเวอร์ (`lib/chat.mjs`) บอก Claude ว่ามีเครื่องมืออะไรบ้าง เช่น `plan_trip`, `find_route`
2. เมื่อ Claude เลือกใช้เครื่องมือ หน้าเว็บจะเปิด `paipai.html` ในกรอบด้านล่าง แล้วเรียก `window.PAIPAI_AGENT`
3. `PAIPAI_AGENT` กรอกฟอร์มและกดปุ่มในเมนูนั้นแทนผู้ใช้
4. หน้าเว็บส่งผลลัพธ์กลับไปให้ Claude สรุปให้ผู้ใช้

ถ้าจะเพิ่มเมนูใหม่ ต้องเพิ่มที่ 3 จุด:
- เครื่องมือใน `lib/chat.mjs`
- ฟังก์ชันใน `PAIPAI_AGENT` (ท้าย `public/paipai.html`)
- ตัวเรียกใน `runTool` ของ `public/index.html`

## ขั้นต่อไป (ยังไม่ได้ทำ)

- อ่านบิลจากรูปถ่าย
- จำข้อมูลส่วนตัวของแต่ละคน เช่น ที่อยู่ ร้านโปรด
- API เดิมของ PAIPAI (`/.netlify/functions/translate` ฯลฯ) ยังเรียกได้โดยไม่ต้องล็อกอิน
