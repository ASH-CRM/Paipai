# ผู้ช่วย AI

แอปผู้ช่วยส่วนตัวสำหรับผู้ใช้กลุ่มเล็ก ล็อกอินด้วย PIN แล้วสั่งงานด้วยการพิมพ์หรือพูดได้ทันที

## มีอะไรบ้าง

- **ล็อกอินด้วย PIN:** เลือกรูปประจำตัว แล้วใส่ PIN ตัวเลข 4–8 หลัก
  - ใส่ผิด 5 ครั้งติดกัน บัญชีจะล็อก 15 นาที
  - ระบบเก็บเฉพาะค่าแฮชของ PIN ไม่เก็บตัว PIN จริง
- **จัดการผู้ใช้ (เฉพาะผู้ดูแล):** เพิ่ม แก้ไขชื่อ/รูป/สี/สิทธิ์ ตั้ง PIN ใหม่ให้คนที่ลืม ระงับการใช้งาน และลบผู้ใช้
- **เปลี่ยน PIN เอง:** เมนูมุมซ้ายล่าง → เปลี่ยน PIN (เครื่องอื่นที่ล็อกอินค้างไว้จะออกจากระบบอัตโนมัติ)
- **หน้าผู้ช่วย:** คุยต่อเนื่องได้แบบ ChatGPT/Gemini
  - คำตอบขึ้นทีละท่อนระหว่างที่ AI พิมพ์
  - ค้นข้อมูลล่าสุดจากเว็บได้
  - ประวัติแชตแยกตามผู้ใช้ คนอื่นมองไม่เห็น
- **สั่งด้วยเสียง:** กด 🎤 แล้วพูด พอหยุดพูดระบบจะส่งให้อัตโนมัติ และกด 🔊 ใต้คำตอบเพื่อฟังคำตอบได้

ไอคอนผู้ช่วยตอนนี้เป็นตัวชั่วคราว เปลี่ยนดีไซน์ได้ที่ `.orb` ใน `public/index.html` และไฟล์ `public/icon.svg`

## วิธีนำขึ้น Netlify (สร้างเว็บใหม่ แยกจาก PAIPAI)

แอปนี้ใช้แพ็กเกจเสริม ต้องให้ Netlify ดึงโค้ดจาก GitHub แล้ว build ให้ **ลากไฟล์ zip ขึ้นเว็บใช้กับแอปนี้ไม่ได้**

1. Netlify → **Add new project → Import an existing project → GitHub** → เลือก repo `ASH-CRM/Paipai`
2. ตั้งค่า build
   - **Branch to deploy:** branch ที่มีโฟลเดอร์ `assistant` (หลัง merge เข้า `main` แล้วเลือก `main`)
   - **Base directory:** `assistant`
   - ช่องอื่นปล่อยตามค่าที่ระบบอ่านจาก `netlify.toml`
3. ตั้ง Environment variables ที่ **Project configuration → Environment variables**

   | ชื่อ | ค่า |
   |---|---|
   | `ANTHROPIC_API_KEY` | คีย์ Claude (ตัวเดียวกับที่ใช้ใน PAIPAI ได้) |
   | `SETUP_CODE` | รหัสลับที่คุณตั้งเอง ใช้ครั้งเดียวตอนสร้างผู้ดูแลคนแรก |

4. กด Deploy แล้วเปิดเว็บ → ใส่ `SETUP_CODE` ชื่อ และ PIN ของคุณ → ได้บัญชีผู้ดูแล
5. เพิ่มผู้ใช้อีก 4 คนที่เมนู **จัดการผู้ใช้** แล้วแจ้ง PIN ให้แต่ละคน (เขาเปลี่ยน PIN เองได้ภายหลัง)
6. บนมือถือ เปิดเว็บแล้วเลือก **เพิ่มลงในหน้าจอหลัก** จะใช้งานได้เหมือนแอป

ข้อมูลผู้ใช้และประวัติแชตเก็บใน Netlify Blobs ของเว็บนี้ ไม่ต้องสมัครฐานข้อมูลเพิ่ม

## โครงสร้างไฟล์

```
assistant/
├── netlify.toml               ตั้งค่า Netlify
├── package.json               แพ็กเกจ: @anthropic-ai/sdk, @netlify/blobs
├── netlify/functions/api.mjs  API ทั้งหมด (/api/*)
├── lib/auth.mjs               PIN, โทเคน, ผู้ใช้, การล็อก
├── lib/chat.mjs               คุยกับ Claude (สตรีม + ค้นเว็บ)
└── public/                    หน้าเว็บ (index.html, manifest.json, icon.svg)
```
