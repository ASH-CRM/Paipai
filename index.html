🎙 โหมดการพูด

🤖 อัตโนมัติ = พูดแล้วหยุด ระบบแปลเอง ไม่ต้องแตะ
🎤 แตะพูด = แตะเริ่ม → พูดยาวได้ไม่จำกัด → แตะอีกครั้งเพื่อแปล (คุมจังหวะเอง 100%)

⚡ ความไวในการแปล

ระยะเวลารอความเงียบก่อนส่งแปล — สั้น = แปลไว แต่เสี่ยงตัดกลางประโยค / ยาว = รอครบประโยคชัวร์

รอเงียบ 0.7 วิ

💡 กวางตุ้ง: กด "เริ่มทดสอบระบบ" ซ้ำได้หลายรอบ — แต่ละรอบระบบจะลองรหัสถอดเสียงตัวถัดไปให้เอง (มี 3 รหัส)

🔧 ทดสอบระบบ

ถ้าพูดแล้วไม่แปล กดปุ่มนี้ ระบบจะตรวจทุกส่วนแล้วบอกว่าติดตรงไหน

เลือกว่าใครพูดก่อน แล้ววางมือถือระหว่างคุณสองคน
ระบบจะฟัง → แปล → อ่านออกเสียง → สลับฝั่งให้เองอัตโนมัติ
